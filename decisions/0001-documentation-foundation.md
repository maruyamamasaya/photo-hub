# 0001: 空のリポジトリに合わせたAI開発基盤
Date: 2026-10-07
Status: accepted

## Context
ユーザーはアプリ機能追加ではなく、AI開発基盤の整備と検索・検証導線の強化を順番に依頼した。調査対象は新規Gitリポジトリで、アプリコードやパッケージ設定は存在しない。

## Decision
文書は役割ごとの正本へ分ける。検索入口は実在するコードだけを案内する。Python標準ライブラリによる文書verifyを設ける。階層AGENTSは責務境界が生じた時点で追加する。

## Reason
実装済みと将来の構想を混ぜず、少ないコンテキストで現在地・探索・検証に到達できるようにする。既存のアプリ検証コマンドがないため、現時点の成果物を検証対象とする。

## Alternatives
- 架空のfrontend/backend構成を先に作る: スタックや責務を未確定のまま固定するため採用しない。
- npm等の基盤を追加する: アプリ未実装で不要な依存となるため採用しない。
- 文書検証を手動だけにする: リンク切れや必須項目の欠落を反復検出できないため採用しない。

## Consequences
Python 3が文書検証に必要。アプリ導入時は実在するlint・テスト・buildをverifyへ統合する必要がある。semantic searchの索引、CI/CD、アプリ検証はまだ存在しない。文書verifyは意味的一致や外部URLを保証しない。
