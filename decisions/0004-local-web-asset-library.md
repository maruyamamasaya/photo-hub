# 0004: ローカルWeb先行の素材ライブラリ
Date: 2026-10-07
Status: accepted

## Context
ユーザーは写真専用から個人用素材ライブラリへの拡張とクロスプラットフォーム利用を希望した。AIは後で追加し、最初はローカルWeb・テスト素材フォルダ・内部DBでUIと使い勝手を検証する方針に合意した。

## Decision
次の開発対象はローカルWeb版とする。PC上のAPI、SQLite、管理フォルダを使い、UIと基本的な素材管理を固めてからAWSへ段階的に移す。iOSは既存SwiftUI実装を保持し、後に共通APIへ接続する。今回は設計のみで実装・改名・AWS作成は行わない。

## Reason
クラウド構築より先に操作と素材モデルを検証できる。iOSの操作性を維持し、保存とメタデータの境界を設けて将来の移行に備える。

## Alternatives
クラウド先行は現時点のUI検証に必要ない。iOSだけを先行するとPC/Webでの素材管理を検証できない。全画面を共通実装にする方針は今は採用しない。

## Consequences
Web版は新規実装が必要。既存iOSとは当初同期せず、後にモデル・API・バックアップの移行を設計する。0002の一台限定・クラウドDB不要という将来範囲はこの方針で見直すが、現在のiOS実装と0003の整合性方針は変更しない。技術選択と初期仕様の提案は [設計文書](../docs/ASSET-LIBRARY-DESIGN.md) に記載する。
