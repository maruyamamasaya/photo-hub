# 検索と素材追加のサイドバー移動
## Request
検索を専用ページにしてサイドバーから開く。素材追加もサイドバーへ移し、一覧タイトルをなくす。
## Investigation
Appのナビゲーション、検索パラメーター、ファイル入力と追加処理を確認。
## Changes
サイドバーに検索と素材追加を配置。検索欄は検索ページだけに表示し、他の一覧へ検索条件を適用しない。見出しとパンくずを除去し、上部余白を縮小。狭幅ではメニューから両機能を開く。
## Files Changed
- web/src/App.tsx
- web/src/styles.css
## Validation
Webビルド成功。実ブラウザーでタグ検索1件、全素材への復帰12件と検索欄非表示を確認。390pxでメニューから検索・素材追加にアクセスできることを確認。追加は既存ファイル入力を継続使用し、新規アップロードは今回未実施。文書verifyとgit diff --check成功。
## Result
一覧を素材中心にし、検索と追加の入口をサイドバーへ集約。
## Remaining Issues
なし。
