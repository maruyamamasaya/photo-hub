# 05: 回復と運用
## 実行プロンプト
未完了追加・削除の起動時回復、派生再生成、欠損表示、容量不足等の失敗保持を仕上げる。Host/origin検証、管理領域外アクセス防止、アップロード上限をテストする。ローカルAPIをLAN公開しない。

テスト素材生成、起動、停止、再起動、サーバー停止中の一式バックアップを再現可能にする。入力素材と管理データをGit除外する。ログに絶対パス・素材内容・認証情報を出さない。クラウド移行は未実施と明記する。
## 完了条件と検証
中断・欠損・再試行・競合・範囲外アクセスの自動検証、専用領域でバックアップ復元照合。実ディスクを満杯にせず容量不足を障害注入で確認する。
