# 04: 整理と検索
## 実行プロンプト
名前・メモ・タグ・お気に入り・コレクションの編集を実装する。名前/元ファイル名/メモ/タグの検索、種別/お気に入り/所属による絞り込み、日時/名前の並び順を追加する。空のコレクションも管理でき、所属解除やコレクション削除で素材は消えない。

Asset revisionで変更競合を409にし、UIは再読み込みを案内する。確認付きごみ箱、復元、確認付き完全削除を実装する。ごみ箱内重複では自動復元しない。
## 完了条件と検証
整理情報と検索結果の一致、競合、所属整合性、ごみ箱・復元・完全削除、再起動保持をAPIテスト。ブラウザでも一連操作を確認する。
