# 02: 保存と取り込み
## 実行プロンプト
Repository/Storage/Previewの境界を設け、SQLiteと.local専用領域に原本をコピーする。JPEG/PNG/WebPを判別し、HEICは原本保管とプレビュー非対応表示を許可する。100MB上限、画像破損検出、SHA256重複防止、安定ID、原本無加工、派生の向き補正を実装する。

ファイル追加と設定済みfixturesフォルダ取り込みを作る。バッチ内の成功/重複/失敗を独立して記録する。stagingとImportItemを永続化し、途中終了後の状態を照合する。派生失敗は原本登録を失敗にせず再試行可能にする。原本ダウンロードも実装する。
## 完了条件と検証
一時専用領域で原本ハッシュ一致、重複、異常ファイル、複数項目の部分失敗、再起動保持、取り込み再試行を自動テスト。入力フォルダの原本は不変。私物素材は探索しない。
