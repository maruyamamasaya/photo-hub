# 03: 一覧と詳細
## 実行プロンプト
素材を探して使うWeb画面を構築する。サイドナビ、検索、絞り込み、ページ分割グリッド、追加操作、詳細プレビュー、ファイル情報、原本取得を作る。実APIを使用し、疑似データだけで完了しない。

複数選択・ドラッグ＆ドロップ・追加中と項目別結果、空状態・読み込み・エラー・プレビュー非対応を表示する。詳細を閉じても検索条件を保持する。キーボード、フォーカス、狭い画面、長い名前を考慮する。生成したテスト素材を明示的に追加できるようにする。
## 完了条件と検証
TypeScriptチェックとWebビルド成功。ブラウザで空一覧→テスト素材追加→一覧→詳細→原本取得まで確認し、API/保存先と照合する。Web狭幅確認はiPhone実機確認の代替としない。
